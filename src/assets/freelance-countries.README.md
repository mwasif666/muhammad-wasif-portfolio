The nine country geometries in `freelance-countries.json` are a subset of the
Natural Earth 1:110m Admin 0 countries dataset (public domain).

Source: https://github.com/martynafford/natural-earth-geojson/blob/master/110m/cultural/ne_110m_admin_0_countries.json

Selected using `ADM0_A3`: PAK, USA, GBR, AUS, CAN, ESP, IND, BGD, TUR.
Only geometry and the country code are retained. The fills indicate freelance
client locations provided by the portfolio owner.
